report `file:line`, a concrete failure scenario and the minimal fix; separate what was verified from what was

## Verification of the fixes

Re-ran the reviewer's own probes against the deployed service, in `enforce` mode:

```

absolute-form http://x/mcp              401   (was the transport)
GET /api/search?q=podman                200   (free doors still free)
POST /api/clients  (no / bad admin)     401
POST /api/clients  (admin token)        200, then DELETE 200
POST /api/keys     (no token)           401
```

194 tests, `tsc` clean, `/health` 200. Auth refusals now appear in the run log as `kind: "auth"`; they
previously left no record at all.

## Open, on purpose

- **No watchdog** on a hung Feynman child. One stuck run blocks the queue until the service restarts.
- **Spend ceilings have nowhere to go.** Feynman's runner has no `--budget` flag, so `budget_usd` is now
  refused rather than dropped; enforcing a ceiling needs a spend check against `feynman research run spend`.
- **`/api/fetch-profile`, `/api/personal/*`** remain open on the bridge. They do not spend money, but they do
  use the owner's logged-in sessions and read personal feeds. Owner decision pending.
- **`clients.json` corruption handling** — an unreadable registry currently reads as empty, and the next
  write would erase every client. It should fail closed instead.
- **502 vs 404** for unknown crawl/batch ids; **cache hits logged as provider calls**.

## Method notes

- Codex `review` with a `[PROMPT]` picked a model this account cannot use
  (`The 'gpt-5.3-codex' model is not supported when using Codex with a ChatGPT account`); the `--base` form
  used the config model and worked, and it rejects `--base` together with a custom prompt.
- Claude's native `/review` and `/security-review` are interactive-only: `claude -p '/review'` returns
  `num_turns: 0`. `/security-review` additionally shells out to `git diff origin/HEAD...` and fails in a repo
  whose `origin/HEAD` does not resolve.
- Both reviewers' findings were treated as claims and re-probed before anything was changed. Every "fixed"
  row above has a live probe behind it; every "open" row is code-read only.
