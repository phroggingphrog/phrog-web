# Code comment audit

Mode: after (session choice). Date: 2026-10-26.

Scope: comments in all TypeScript files under `src/` and deployment scripts/configuration under `deploy/`. Vendored upstream projects under `engines/`, generated output, dependencies, documentation prose, and executable strings are excluded. This is a comment hygiene audit, not a correctness or security review.

No source comments or executable code were changed. Findings are grouped into approval units; approve individual numbers before fixes. All findings are LOW under R-31 (the purpose test, a Quality Lock); no HIGH findings were identified in this scope.

## Findings

1. **LOW | R-31 | Numbered declaration labels.** Numbered headings repeat route names, tool names, or declarations instead of explaining a constraint.
   - Locations: `src/index.ts:30,64,94,134,144,229,258`; `src/adapters/mcp/server.ts:31,49,67,86,105,124,156,179,195,213,231,248,271`; `src/providers/research.ts:47,109`; `src/wiki/embeddings.ts:17,59`.
   - Proposed fix: remove redundant labels and numbering. Where a heading identifies an engine or a fallback property that the declaration does not express, keep that information in a short sentence-case comment.

2. **LOW | R-31 | Decorative separators.** Repeated hyphens decorate section labels without adding information.
   - Locations: `src/providers/media.ts:60,103,166,205`; `src/providers/crawl.ts:87,165,238`; `src/providers/compat.ts:36`.
   - Proposed fix: remove decoration; retain plain section names only where they help navigate a group. Preserve the `sitecrawl.crawl_site` port reference and the Feynman concurrency constraint, “one at a time.” Remove the empty “main” label.

3. **LOW | R-31 | Parsing and indexing narration.** Comments repeat the immediately following transformation or function calls.
   - Locations: `src/providers/fetch.ts:22,26,33,41`; `src/providers/deepwiki.ts:74`; `src/wiki/vault.ts:77`.
   - Examples: “Extract title,” “Normalize repo name,” and “Embed and index note in SQLite.”
   - Proposed fix: remove those comments; preserve the adjacent code and its whitespace. Keep the separate note explaining the JavaScript-rendered page heuristic in `fetch.ts:81`.

4. **LOW | R-31 | Empty helper and operation labels.** Generic labels name an operation without giving a reason or constraint.
   - Locations: `src/config.ts:57,64`; `src/index.ts:27,122,345`; `src/adapters/mcp/server.ts:23,419`; `src/providers/search.ts:174,209`.
   - Examples: “ignore,” “Helper for MCP text response,” “Start Server,” and “Determine pipeline.”
   - Proposed fix: remove these labels. Keep any substantive adjacent pipeline explanation as a separate comment; do not invent a reason for swallowing configuration read errors.

5. **LOW | R-31 | Research workflow narration.** Comments walk through operations already named by variables and calls.
   - Locations: `src/providers/research.ts:56,130,136,165`.
   - Examples: “Ensure outputs directory exists” and “Spawn headless Feynman process.”
   - Proposed fix: remove the four comments. Retain the separate in-memory job registry note, which makes the storage lifetime visible to readers.

6. **LOW | R-31 | Deployment constraint spread over three lines.** The proxy note contains useful protocol and fallback information, but exceeds the comment skill's two-line limit.
   - Location: `deploy/egress/privoxy.conf:2-4`.
   - Proposed replacement, preserving the routing constraint and fallback:
     ```conf
     # All traffic uses the SSH tunnel: Crawl4AI CONNECTs to pinned IPs, preventing hostname rules.
     # Direct homelab egress uses the separate crawl4ai-home container.
     ```
