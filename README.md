# Phrog Web 🌐

Unified, agent-agnostic web search, page extraction, and deep research hub.

## Features
- **Fast Search**: Powered by local SearXNG multi-engine aggregation + TinyFish Search fallback.
- **Clean Fetch**: Markdown content extraction via Trafilatura + TinyFish Fetch (resilient against bot protection).
- **Deep Research**: Multi-hop research pipeline drawing from Feynman and Vane.
- **REST API + Pluggable Agent Templates**: Usable via standard HTTP or as an agent tool/MCP.
